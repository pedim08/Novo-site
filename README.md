# NobreTech — loja de hardware (projeto de portfólio)

Loja virtual front-end feita com HTML, CSS e JavaScript puros: catálogo, busca, filtros, página de cada produto (com abas, avaliações e frete simulado), favoritos, carrinho e pedido simulado, banner rotativo e layout responsivo.

## Como rodar
Abra `index.html` no navegador ou publique no GitHub Pages / Netlify.

## Imagens
- Produto: salve `img/produtos/<id>.jpg` (o id é o campo `id` em `produtos.js`).
- Banner: salve `img/banners/banner1.jpg`, `banner2.jpg` e `banner3.jpg` (1200x400 px).
Sem o arquivo, o site usa as imagens `.svg` de reserva.

## Aviso
Projeto de demonstração: preços, descontos e pagamento são fictícios.
